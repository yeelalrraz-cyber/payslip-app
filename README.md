# תלוש שכר למטפלת סיעודית

אפליקציה לעריכת תלושי שכר לעד 3 מטפלות, עם היסטוריה, קופה לזכויות סוציאליות והורדת PDF בעברית ובאנגלית.

- `index.html` – האפליקציה כולה.
- `firestore.rules` – כללי האבטחה של Firebase: רק בעלת האפליקציה ומי שהיא הוסיפה יכולים לקרוא ולכתוב.

כל עוד לא הוגדר Firebase בקובץ, הנתונים נשמרים בדפדפן בלבד.
